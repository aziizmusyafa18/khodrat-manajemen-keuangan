Integrasi Google Spreadsheet
Hubungkan ke Google Apps Script Web App sebagai database.

Seluruh data kas akan tersimpan di Google Drive Anda secara otomatis. Tanpa biaya hosting tambahan.

Kosongkan untuk kembali ke Mode Demo (data lokal browser).
Cara Setup Cepat:
  1. Buka Google Sheets baru di sheets.new.
  2. Pilih Ekstensi > Apps Script.
  3. Paste seluruh isi file google-apps-script/Code.gs.
  4. Klik Deploy > New deployment > Web app.
  5. Pilih Who has access: Anyone, salin URL → tempel di atas.
